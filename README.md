# 🌡️ Cidades com Altas Temperaturas

[![GitHub Pages](https://img.shields.io/badge/🌐-Site%20Online-blue?style=for-the-badge)](https://leandrostanger.github.io/CidadesComAltasTemperaturas/)
[![GitHub](https://img.shields.io/badge/📂-Repositório-black?style=for-the-badge)](https://github.com/LeandroStanger/CidadesComAltasTemperaturas)

Um projeto web interativo que exibe informações sobre cidades com altas temperaturas ao redor do mundo, proporcionando uma visão clara e organizada sobre condições climáticas extremas.

## ✨ Funcionalidades

- **🌍 Mapa Interativo:** Visualização geográfica das cidades com altas temperaturas
- **📊 Dashboard de Temperaturas:** Exibição clara e organizada dos dados climáticos
- **🔍 Sistema de Filtros:** Filtragem por continente, país ou faixa de temperatura
- **📱 Design Responsivo:** Interface adaptável para desktop e dispositivos móveis
- **🔄 Atualização em Tempo Real:** Dados climáticos dinâmicos e atualizados
- **🎨 Visualização de Dados:** Gráficos e indicadores visuais intuitivos

## 🚀 Como Usar

### Acesso Online
Acesse o projeto diretamente através do GitHub Pages:  
**[https://leandrostanger.github.io/CidadesComAltasTemperaturas/](https://leandrostanger.github.io/CidadesComAltasTemperaturas/)**

### Execução Local
Para executar o projeto em sua máquina local:

```bash
# Clone o repositório
git clone https://github.com/LeandroStanger/CidadesComAltasTemperaturas.git

# Acesse a pasta do projeto
cd CidadesComAltasTemperaturas

# Abra o arquivo index.html no navegador
# Ou utilize um servidor local:
python -m http.server 8000
# ou
npx http-server
```

## 🌡️ Características Principais

- **Monitoramento Global:** Acompanhamento de temperaturas em diversas regiões
- **Alertas de Calor:** Identificação de condições climáticas extremas
- **Comparação Entre Cidades:** Análise comparativa de dados térmicos
- **Histórico de Temperaturas:** Dados temporais para análise de tendências
- **Interface Intuitiva:** Navegação simples e experiência do usuário otimizada
